# intelligence-studio

## نظام إدارة شركة المقاولات (Excel ERP)

مصنف إكسل احترافي ومؤتمت بالكامل لإدارة شركة مقاولات، بواجهة عربية بالكامل.

**الملف:** `نظام_إدارة_شركة_المقاولات.xlsx`

### هيكل النظام

| الورقة | الوصف |
|---|---|
| لوحة التحكم | ملخص تنفيذي (مبيعات، مصروفات، أرباح، رواتب) مع رسوم بيانية تتحدث تلقائياً |
| المبيعات | سجل الفواتير مع ملخص أسبوعي/شهري وأفضل 10 عملاء |
| المصروفات | سجل المصروفات مع ملخص حسب الفئة والنسب المئوية |
| سجل عمل الموظفين | تسجيل الحضور اليومي واحتساب الإضافي تلقائياً (بعد 23:00، مع دعم الاستمرار بعد منتصف الليل) |
| الرواتب | كشف الرواتب الشهري الكامل (يُبنى تلقائياً من قائمة الموظفين) + جدول السلف والخصومات |
| دليل الاستخدام | شرح كامل لطريقة الاستخدام |
| الإعدادات *(مخفية)* | قاعدة البيانات الرئيسية: الموظفون، فئات المصروفات، طرق الدفع، إعدادات الشركة |

### مبدأ التصميم

كل صفحة تسحب بياناتها من ورقة **الإعدادات** الوحيدة عبر Excel Tables و XLOOKUP/FILTER/SUMIFS
الديناميكية - فإضافة موظف أو فئة مصروف جديدة في الإعدادات تنعكس تلقائياً في كل الصفحات
(القوائم المنسدلة، الرواتب، التقارير، لوحة التحكم) دون تعديل أي معادلة.

خلية واحدة في الإعدادات ("الفترة الحالية") تتحكم بفترة التقارير في المصنف بالكامل.

كلمة مرور حماية الأوراق: `2026$Construct` (لفك الحماية فقط عند الحاجة لتعديل هيكل الصفحات).

### إعادة التوليد

المصنف مُولَّد برمجياً عبر `tools/generate_workbook.py` (Python + openpyxl)، ما يجعل
تعديل الهيكل أو التوسع المستقبلي أسهل وأكثر قابلية للصيانة من التعديل اليدوي المباشر.

```bash
pip install openpyxl
python3 tools/generate_workbook.py
```
